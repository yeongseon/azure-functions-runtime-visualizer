# Contributing

We welcome focused issues and pull requests improving the Azure Functions
Runtime Visualizer. Preserve source-log fidelity and the privacy boundary:
do not upload, expose or publish potentially sensitive runtime traces.

## Unified PR Review

The same review criteria apply to human-authored and AI-assisted changes
(OpenCode, Codex, Claude Code, ChatGPT, Copilot, etc.). Submit tests,
documentation, an explanation of changes, and any local validation gaps.
Use required **GitHub CI** checks on the final head as authoritative;
local checks are recommended but not an additional merge gate. Oracle,
Copilot and other AI reviewers are optional and **advisory**.
A maintainer checks security, factual trace interpretation, CI and
remaining findings before making the final merge decision. Runner hosting
does not define the policy; do not weaken deployment, CI or data controls.
